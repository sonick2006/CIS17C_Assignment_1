# CIS17C_Assignment_1
Assignment_1 CIS_17C - Nicholas Abdulkarim

In this assignment, I created a restuarant ordering system which manages many different parts of the restaurant work chain.

Key Features:
    Menu Management:
        Add and remove items on the menu
    Order Creation and Modification:
        Each table can create an order
        Items can be added to the order per request.
        The system then calculates the total cost of the order after it is closed.
    Table Management:
        Track table occupancy and its orders
    Kitchen Queue:
        Orders will be submitted into a first-in-first-out processing order.
    Payment Processing:
        Completing an order clears the table and adds the total to restaurant sales.
    Sales Reporting:
        Displays the total amount earned from completed orders.
